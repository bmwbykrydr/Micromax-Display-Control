Connection method

Messages

READ loads the saved message from the display controller. SAVE replaces typed messages and saves to permanent memory. Maximum 64 characters. Supported character set: ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789-!\"#$%&()*,./\\:;?@[]^_+<=>

Wi-Fi setup over Bluetooth

Scan nearby 2.4 GHz Wi-Fi networks, select a network or enter its SSID, type the password, then SAVE and CONNECT. The original hardware Wi-Fi wizard is still available.

Password is not displayed after saving. Wi-Fi names and passwords are transferred to the ESP32 via BLE, not to the hosting website.

Wi-Fi status: Not checked

Virtual buttons

Tap to simulate the original physical buttons. Turn EDIT on and select a message to use the manual editor. Direct message SAVE requires EDIT off.

EDIT switch

During manual editing, choose a message using the buttons below.

Retirement target

The new date is saved by the ESP32. Bluetooth and internet both support this setting.

Connection activity

Ready. Choose Internet or Bluetooth, then connect. Connection diagnostics build 2.

Bluetooth communicates directly with a nearby ESP32. Internet uses a separate Micromax Firebase project.

Compatibility

Android: Chrome on an HTTPS page. iPhone: Bluefy Web BLE Browser on an HTTPS page (Safari does not support Web Bluetooth). Use the supplied Micromax_Standalone.ino sketch. Wi-Fi provisioning, hold buttons, and the EDIT switch are available in Bluetooth mode. Internet mode supports message READ/SAVE, short button taps, and retirement date.
